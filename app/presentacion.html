Demo: evaluar una solicitud

La interfaz web (Streamlit Cloud) le pide todo a la API publicada en Render.

  1. Cargamos el perfil de riesgo medio y lo evaluamos: aprobado, banda 2, prima 6,05%.
  2. Lo cambiamos a alto riesgo: rechazado, banda 7.
  3. Mostramos el pedido y la respuesta JSON de la API.
  4. Si hay tiempo: un CSV con varias solicitudes, o un dato inválido para ver el error.

Límites y próximos pasos
  1. La prima es para toda la vida del préstamo; pasarla a tasa anual requiere modelar cuándo ocurre el default
  2. Solo vemos préstamos que Lending Club aprobó, no los que rechazó
  3. Si cambia el ciclo económico, hay que reestimar la calibración
  4. Monitorear el modelo con préstamos nuevos y reentrenar cuando pierda poder
